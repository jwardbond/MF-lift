This folder contains the most recent model checkpoints for models trained on the rectangular (r), triangular (t), semicircular (s), and trapezoidal (p) datasets.

The `r0` checkpoint is the model trained only on the un-augmented rectangular dataset, which we use for comparison to the model from [Su et al.](https://pubs.rsc.org/en/content/articlelanding/2021/lc/d1lc00225b).
